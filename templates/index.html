OpenPrescribing Data Change Monitor

The OpenPrescribing Data Change Monitor identifies new or changed items in newly published prescribing data and highlights changes that may affect OpenPrescribing.

Primary care

English Prescribing Data (EPD)

The monthly change reports identify:

  • New or changed chemical substance descriptions
    For example, a new drug being prescribed in primary care for the first time, or an existing chemical substance description changing.
  • New or changed BNF codes
    For example, a new drug or new formulation or strength of an existing drug being prescribed in primary care for the first time, or an existing BNF code changing.
  • New or changed BNF descriptions
    For example, updated or modified descriptions of existing items.

View EPD change reports

Secondary care

Secondary Care Medicines Data (SCMD)

The monthly change reports identify:

  • New Virtual Therapeutic Moieties (VTMs)
    For example, a new therapeutic moiety appearing in secondary care medicines data for the first time.
  • New Virtual Medicinal Products (VMPs)
    For example, a new medicinal product or formulation appearing in secondary care medicines data for the first time.

View SCMD change reports

OpenPrescribing measure tests

New items in English Prescribing Data are checked against OpenPrescribing measures to identify changes that may require review. These tests help to ensure the accuracy and relevance of OpenPrescribing's prescribing tools.
